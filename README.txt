PURBELI MASU KO ACHAR — WEBSITE
================================

HOW TO OPEN
  Double-click index.html. No install needed.
  (Needs internet only for the Google Fonts: Yatra One + Mukta.)

HOW TO ADD YOUR FACEBOOK / INSTAGRAM / TIKTOK LINKS
  Open js/config.js in Notepad and paste your page links between the quotes:
      facebook:  "https://www.facebook.com/yourpage",
      instagram: "https://www.instagram.com/yourname",
      tiktok:    "https://www.tiktok.com/@yourname"
  Icons with an empty link stay hidden automatically.

HOW TO CHANGE THE PHONE NUMBER OR THE WHATSAPP MESSAGE
  Same file: js/config.js

FILES
  index.html        the page
  css/style.css     colours, layout, mobile design
  js/config.js      phone, WhatsApp message, social links
  js/main.js        menu, WhatsApp/call buttons, floating jar
  images/           optimised logo, banner and jar images

PUT IT ONLINE
  Upload the whole folder to any static host (Netlify, Vercel, GitHub Pages,
  Cloudflare Pages, or normal web hosting).
